## 📝 Study Notes & Concepts
Network reconnaissance and port enumeration using Nmap: TCP SYN stealth scanning (-sS), TCP Connect scanning (-sT), UDP scanning (-sU), service version detection (-sV), OS fingerprinting (-O), and Nmap Scripting Engine (NSE).

## 💻 Practical Commands & Lab Exercises
```bash
nmap -sS -p- -T4 -v scanme.nmap.org
nmap -sV -sC -p 22,80,443 -oA nmap_scan scanme.nmap.org
```

---

## 🛡️ Security Perspective & Key Takeaways
> **Core Rule:** Nmap determines open network doors. SYN scans avoid completing the full 3-way handshake to minimize overhead. NSE scripts automate vulnerability verification and service interrogation.

* **Attacker View:** Adversaries abuse implicit trust, default configurations, unauthenticated protocols, and missing verification boundaries.
* **Defender View:** Security practitioners enforce least privilege, segment network boundaries, validate input server-side, and enable comprehensive endpoint and network telemetry.
